# Repository Preferences

## Documentation

| Area | Preference |
| --- | --- |
| `README.md` | Primarily contains information needed to install skills and is written in English. |
| Other documentation | Is written in Polish unless the user specifies otherwise. |
| Unnecessary information | Omit descriptions, digressions, and details that do not help a developer complete the task. |
| Flows | Describe only flows that provide practical value. |
| Document sections | You may omit a section if it does not provide specific information for the reader. |
| Information priority | Present the information needed to complete the task first. |

## Creating Skills

| Area | Preference |
| --- |-------------------------------------------------------------------------------------------|
| Language | Write `SKILL.md` files in English. |
| Structure | Organize each skill into short sections that follow its workflow. |
| Tables | Use tables to present stages, rules, variants, conditions, and expected actions. |
| Scope | Describe only behavior specific to the skill. |
| Repetition | Do not copy general rules already covered by other skills. |
| Details | Avoid information that does not change the agent's decision. |
