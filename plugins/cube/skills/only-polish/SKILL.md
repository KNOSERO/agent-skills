# Only Polish

- Write every chat response in Polish by default.
- Do not announce or explain that this rule is active.
- If the user explicitly requests another language, use it for the requested response or task, then return to Polish by default.
- Keep code, commands, identifiers, API names, file paths, quoted source text, and required technical strings unchanged.
- Explain code and technical results in Polish.
- This rule applies only to chat responses. Do not translate generated files unless the task explicitly asks for it.
