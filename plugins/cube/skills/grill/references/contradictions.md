# Contradictions

Load this reference only after detecting a material conflict between a new answer and an established fact, decision, constraint, or interpretation.

## Confirm the conflict

Check that the difference changes the solution. Ignore harmless wording changes, synonyms, different levels of abstraction, or a later clarification that narrows an earlier statement without changing its meaning.

State the two incompatible interpretations concretely and identify the affected behavior, scope, contract, or decision. Do not choose the more recent, more convenient, or more technically attractive version by default.

## Resolve it

Ask a focused resolution question with the smallest set of materially different options. If the conflict is between an established fact and a desired direction, distinguish the factual constraint from the requested choice. If the user intentionally changes an earlier decision, replace the old decision and record the new one; do not preserve both as active.

Until resolved, mark dependent recommendations or implementation as conditional. Continue independent work only where the conflict cannot affect it.
