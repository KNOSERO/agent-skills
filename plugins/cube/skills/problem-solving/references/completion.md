# Completion states

Load this reference when the result is partial, conditional, blocked, deferred, or spans multiple unresolved branches.

- **SOLVED** — evidence and confirmed decisions support a solution, with no material blocker capable of changing its main direction.
- **SOLUTION-READY** — the solution is sufficiently defined; remaining unknowns are non-blocking execution or validation details.
- **PARTIALLY RESOLVED** — material facts or decisions remain unavailable or deferred, but a valid partial or conditional solution exists.

For a partial result, state what is solved, the exact unresolved fact or decision, which part depends on it, and what remains valid regardless of the answer. Use explicit branches such as “if A, X; if B, Y”. Do not describe a result as solved when a material blocker could change the main solution. End with the next valid action only when it is useful and justified.
